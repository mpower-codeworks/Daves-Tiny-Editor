Opening an existing file:
-------------------------
Drag and drop it onto DTE.

Creating a new file:
--------------------
Double-click DTE to run it.  A new  file  "f" will  be
automatically created. If f  already exists, then  DTE
simply opens that.  Edit the new  file and Save.  Quit
DTE and rename f to whatever you want.

Saving a file:
--------------
Press F9 or click the  System Menu->Save. There is  no
"Save-As".


Closing DTE
-----------
DTE now has  unsaved-file protection. If  the file  is
unsaved (* appended to the name in the title bar), the
GUI "X" and  the System  Menu "Close"  (or Alt-F4)  do
nothing. They are only enabled if a file is  unchanged
since last save.

X! (X bang) in the  system menu overrides the  unsaved
protection and allows the user to "throw away changes".

Searching the file
------------------
Highlight any text in the file and press F3 to  search
forwards or F2 to search backwards. DTE will highlight
each next found instance for every F2 or F3  keypress.
End of file and beginning  of file both silently  wrap
to the other end.

One-time Replace (repeatable)
-----------------------------
DTE has  no  Replace  dialog,  but  a  quick  one-time
replace is available. Copy the replacement text to the
Windows clipboard, highlight the text to find, and use
F2 or F3 to move to the desired instance. Press Ctrl+V
and the highlighted instance  is immediately replaced.
To repeat, press  Ctrl-Home to jump to the search term
at the top of the file and highlight the text again.

Printing a file
---------------
F12  immediately  prints   to  the  active   (default)
printer. If the active printer  is PDF, a dialog  will
open to  choose a  file name  to save  as. This  is  a
trick. DTE  is actually  calling Notepad  with the  /p
flag. The  user only  briefly  sees the  Notepad  "Now
printing" dialog.  The Notepad  editor never  appears.
Note: F12 is disabled unless the file has been saved.

DTE_SETUP
---------
Place DTE_SETUP.exe  beside  dte.exe  and  run  it  to
change DTE's font  and startup state.  First  choose a
font. Then choose whether DTE should start Windowed or
Maximized.

The  selected  settings  are  written  directly   into
dte.exe. No INI  file or Registry  settings are  used.
Font names  may contain  up to  19 characters.  Longer
font names are refused. Running DTE_SETUP expands  the
configured dte.exe to 1024 bytes.

Word Wrap
---------
Word wrap is always on.

Keyboard Navigation
-------------------
Arrow keys:           Move cursor in that direction
Home                  Start of line
End                   End of line
Ctrl + Home           Top of file
Ctrl + End            End of file
Page Up               Scroll up
Page Down             Scroll down
Ctrl + Left           Move to previous word
Ctrl + Right          Move to next word






Selection
---------------
Shift + Arrow         Extend selection
Shift + Home          Select to start of line
Shift + End           Select to end of line
Ctrl  + Shift + Home  Select to top of file
Ctrl  + Shift + End   Select to end of file
Ctrl  + A             Select all
L/Click & Drag        All of the above

Editing
-------
Backspace             Delete character before cursor
Delete                Delete character at cursor
Ctrl  + Backspace     Delete previous word
Ctrl  + Delete        Delete next word
Enter                 Insert newline

Clipboard:
----------
Ctrl  + C             Copy
Ctrl  + Insert        Copy
Ctrl  + X             Cut
Shift + Delete        Cut
Ctrl  + V             Paste
Shift + Insert        Paste

Undo / Redo:
------------
Ctrl  + Z             undo
Ctrl  + Y             redo

Right-Click Editor Menu:
------------------------
Disabled. Use keyboard commands.

System Menu
-----------
Can be accessed by upper left icon or
by r/click anywhere in the title bar.

DTE Max Editable File Size
--------------------------
100 MB files verified as working.
